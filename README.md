# MyTalents Tutor Workday

A hackathon project to simplify teaching operations and learning support at MyTalents.

**Status:** Repository setup only. Application development and technology choices are pending the team's next instructions.

## Product direction

Create an LMS-inspired workspace for teachers, managers and students. Reduce repeated data entry, help staff coordinate follow-up work, and make daily progress easier to see.

The question-solving experience is currently a black box. Its eventual outputs can feed student records, follow-up tasks and reporting; its implementation is outside the initial setup.

## Proposed modules

| Area | Proposed capabilities |
| --- | --- |
| Teacher portal | Work WeChat message handling, test marking/review, daily reports, student briefings and student management |
| Manager access | Teacher capabilities plus daily report review and sign-off |
| Student portal | Upload scanned papers, view the mistake bank, record exam data, book Q&A and view learning progress |
| Shared features | Calendar, mistake bank, role-based access and Google ecosystem synchronization |

These are planning boundaries, not implemented features. External integrations are not connected yet.

## Visual direction

Use the supplied LMS reference for a dark navy navigation area, clear quick-access tiles, a daily schedule panel and a readable modular dashboard. Apply MyTalents' own identity and content.

## Collaboration

- Work on a feature branch and open a pull request to `main`.
- Agree on the stack and module responsibilities before scaffolding the application.
- Keep credentials and real student records out of the repository; use synthetic examples for the demo.

There are no installation, run or test commands yet because the application has not been scaffolded.
